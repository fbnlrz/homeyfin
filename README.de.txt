Jellycontrol bringt deinen selbstgehosteten Jellyfin-Medienserver in Homey. Jedes Homey-Gerät steht für einen einzelnen Jellyfin-Benutzer, und die Wiedergabe folgt diesem Benutzer automatisch zu dem Client, auf dem er gerade schaut — abends der Wohnzimmer-TV, unterwegs das Smartphone — damit deine Flows auf das reagieren können, was tatsächlich läuft.

Dies ist eine inoffizielle App und steht in keiner Verbindung zur Jellyfin Foundation und wird von ihr nicht unterstützt. Jellyfin ist eine Marke der Jellyfin Foundation.
