Jellycontrol brings your self-hosted Jellyfin media server into Homey. Each Homey device represents a single Jellyfin user, and playback automatically follows that user to whichever client they are watching on — the living-room TV in the evening, a phone on the go — so your home can respond to what is actually playing.
